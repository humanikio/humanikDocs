---
title: How Auto works
description: Auto picks a model for each request, so simple work costs less and hard work still gets a strong model.
---

**Auto** is the default in Nova's model picker. It does not run one fixed model.
Every time Nova needs a model, Auto asks **Jev** which model should answer, and
that model does the work.

Jev is a small decision model. It does not write the answer itself. It reads the
request, works out what kind of work it is, and picks the model and the amount of
reasoning that fit. You pay for the model that answered, so a turn that a smaller
model can handle costs less than it would on the strongest model.

## What Jev looks at

For each request, Jev weighs three things:

| | What it asks |
| --- | --- |
| **What the task needs** | Is this a lookup, a rewrite, a plan, code, a long chain of tool calls? |
| **How hard it is** | Could a smaller model get this right, or is it likely to go wrong? |
| **The benefit of a stronger model** | Would a stronger model produce a better result, or only a more expensive one? |

It then balances those against the estimated cost. Auto uses a **balanced**
setting: it does not always pick the cheapest model, and it does not always pick
the strongest. It picks the strongest model only when the task is likely to be
better for it.

Jev also picks **how hard the model should think** (its reasoning effort). A
quick answer does not pay for long reasoning it does not need.

## Longer tasks

When Nova works through a task in several steps, such as reading records, then
calling tools, then writing a summary, Jev can keep the same model, raise or lower
the reasoning effort, or switch models between steps as the task changes. The
model you see on one step is not a promise about the next.

## What you pay

Auto always runs on our account and is billed to your credit, the same as before.
It does this even when your workspace has your own model account assigned. See
[The default runs on credits](/docs/models#the-default-runs-on-credits-deliberately).

What changes is the price per turn. There is no single rate for Auto, because each
turn is charged at the price of the model that answered it. In your usage, a Nova
run on Auto shows the model that answered. For a run with several steps, it shows
the model of the last step, and the cost is the total of every step.

<Callout>
  **Auto is a cost preference, not a price cap.** Jev favours cheaper models when
  they are good enough, but a hard request can still go to a strong, more
  expensive model. To cap what Nova can spend, set a [budget](/docs/spend/budgets).
</Callout>

## When Jev cannot be reached

If Jev is unavailable for a request, Auto answers that request on **Claude Sonnet
5** instead, billed to your credit in the same way. Your message still gets an
answer, and nothing is charged for the attempt that did not go through.

## When you want one fixed model

Pick a model yourself. Every model under **Platform models** in the picker runs
that exact model every time, billed to your credit. A model under **Your key**
runs on your own account. See [Choosing a model](/docs/models/choosing-a-model).

## What Auto applies to

| | Uses Auto |
| --- | --- |
| Nova, when your model is set to Auto | Yes |
| Nova [scheduled tasks](/docs/nova/scheduled-tasks), when their model is Auto | Yes |
| Offices | No. An office runs on the model set for it. See [Choosing for an office](/docs/models/choosing-a-model#choosing-for-an-office) |
