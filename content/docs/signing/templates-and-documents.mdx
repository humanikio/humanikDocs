HumaDocs keeps two things apart:

| | Template | Document |
| --- | --- | --- |
| What it is | A PDF, the roles who sign it, and the fields each role fills in | One copy of a template, with real people in each role |
| Used for | Preparing a PDF once and sending it many times | One signing, from draft to finished |
| Changes reach | New documents only | This document only |

Sending copies the template's PDF, roles and fields into the document. Changing the template
afterwards never changes a document that was already made from it.

## Templates

<Steps>

<Step>
**Upload a PDF.** Open **HumaDocs**, go to **Templates** and select **Create template**. The
PDF can be up to 25 MB and 200 pages. A password protected PDF cannot be used: remove the
password and upload it again.
</Step>

<Step>
**Name the roles.** A role is a part someone plays, such as "Client" or "Manager", not a
person yet. A template has between 1 and 10 roles.
</Step>

<Step>
**Place the fields.** Drag fields onto the pages and give each one to a role. Select several
fields to move, copy or delete them together. To give the pages more room, hide the panel on
either side with the button at its top. A hidden panel stays as a narrow strip with its name on
it: select the strip to open the panel again.
</Step>

<Step>
**Save.** The editor shows whether your changes are saved, and asks before you leave with
changes that are not. If something is wrong, such as a field past the edge of the page or a
field for a role that no longer exists, nothing is saved and the editor lists every problem.
It also lists things worth a look that do not stop the save: two fields on top of each other,
a role with no signature, or a field over printed words. Select one to select its field.
</Step>

</Steps>

**Archive** is in the **⋮** menu at the top of the template editor. Archiving a template hides it from the list; documents already made from it are not affected.

### Duplicate a template, and replace its PDF

When the wording of a document changes but its layout does not, keep the fields and swap the
file behind them.

- **Duplicate.** In **Templates**, open the menu on a template's row and select **Duplicate**, or
  open the **⋮** menu at the top of the template editor and select **Duplicate**. A copy named "(copy)" opens in the
  editor with the same PDF, roles and fields.
- **Replace PDF.** In the template editor, select **Replace PDF** on the **PDF** card in the left
  panel, and choose the new file. When the left panel is hidden or the window is narrow, it is
  in the **⋮** menu at the top. Every field keeps its place on the page.
- **Drop a file.** Drag a PDF onto the editor and drop it on **Replace this PDF**, or on
  **Duplicate, then replace** to make a copy of the template with the new file. The template you
  started from does not change.
- **Duplicate and replace.** The same copy is on the **PDF** card. The copy opens with the new
  file in place.

Save your changes first: these buttons are off while there are unsaved changes.

Before you replace, HumaDocs compares the new pages with the old ones:

| What it finds | What happens |
| --- | --- |
| The pages line up | Every field stays where it is |
| A page is a different size | The fields keep their place on that page but may stretch. Check them after the swap |
| The new PDF has fewer pages, with fields on the missing pages | You choose: **delete** those fields, or **move** them to the last page at the same place. Replace stays off until you choose |

After the swap, the editor shows the new pages under the same fields and a notice that says
what changed: how many fields moved or were deleted, and which pages changed size. Fields that
moved to the last page are selected, so you can drag them off other boxes together. Anyone
else with the editor open sees the new version within a few seconds, the same as any other
change to the fields.

An archived template can be duplicated, which brings an old layout back, but its PDF cannot be
replaced.

The new file replaces the old one. HumaDocs keeps a note of the old file's name and
fingerprint, not the file. Documents already made from the template keep their own copy and do
not change. HumaDocs never edits the text inside a PDF: change the file elsewhere, then replace it.

### Let Nova place and review the fields

Both editors have an **Auto place and review document fields** card at the top of the left
panel. Select it and Nova opens on the right. Nova finds the blanks on the pages (lines to
write on, answer boxes and checkboxes), reads the words around each one, and decides the field
type, the role it belongs to, and whether it is required. If the document already has fields,
Nova also checks them and suggests fixes.

Nova shows every change on one card, grouped by page. Nothing is saved until you select
**Approve**. The fields then appear in the editor within a few seconds. Save your own changes
before you start, so Nova works on what you see. The card is shown only to people who can
change the fields.

Nova places fields on top of the PDF and never changes its text. A scanned PDF has no text
Nova can read, so its fields must be placed by hand. See
[Nova and HumaDocs](/docs/signing/nova-and-humadocs).

### When someone else changes the fields

If Nova or a teammate saves the fields while you have the editor open, the editor shows their
version within a few seconds. If you have unsaved changes, it asks first: **Load their
version**, or **Keep mine** and save over theirs. A save made from an older version is never
applied without asking, so nobody's work is lost without warning.

### Fields

| Field | What the signer does |
| --- | --- |
| Signature | Draws, types or uploads a signature |
| Initials | Draws, types or uploads initials |
| Date signed | Nothing. Today's date appears, locked, as soon as they sign, in their own time zone |
| Text | Types a short answer |
| Name | Types their name |
| Email | Types an email address |
| Checkbox | Ticks it, or leaves it empty |

Every field except the date signed can be **required** or **optional**. A person cannot
finish until their required fields are filled in.

## Documents

Select **Use** beside a template, or **New document** and choose a template. HumaDocs makes a
draft document and opens it in the document editor. In the draft you can:

- **Choose the people.** One person per role: pick a CRM contact, or type a name, email
  address and mobile number. You can replace, remove or combine people before sending.
- **Change the fields.** Add, move or remove fields for this document only. The template
  stays as it was.
- **Fill in values yourself.** Type a value into a field before sending, for example a price
  or a start date. The signer sees it filled in and cannot change it, unless you tick
  **Signer can change it**.
- **Set the signing order.** See below.
- **Replace the PDF.** Select **Replace PDF** on the **PDF** card in the left panel (or in the
  **⋮** menu at the top), or drop a PDF onto the editor, to put a new file behind this draft's fields, with the
  same checks as a template. Only the draft changes, not its template. A value you filled in
  stays with its field when the field moves and goes with it when the field is deleted. The
  replace is listed in the document's activity and in the audit pages of the finished
  document. Once a document is sent, its PDF can no longer be replaced.

A draft saves even when it is incomplete. Every check runs when you send it: each role needs
a person and at least one field, and every required value you filled in must be valid.

**Save as template** (in the **⋮** menu at the top) makes a new template from the document's PDF, roles and fields. It never
changes the template the document came from. A draft whose PDF you replaced becomes a template
with the new file.

**Duplicate** makes a new draft from any document, in any status, without its people, values or
sign-by date. The original keeps its state. To change the PDF of a document that was already
sent, duplicate it and replace the PDF of the new draft.

## Signing order

Each role has an order number.

- **Same number:** those people sign at the same time.
- **Higher number:** those people are invited only after everyone before them has finished.

If every role has the same number, everyone is invited at once. Every person has a link as
soon as the document is sent. A person who opens their link before their turn sees who signs
first, and can sign with the same link when their turn comes.

## Statuses

| Status | Means |
| --- | --- |
| Draft | Not sent. You can still change everything |
| Out for signing | Sent. Waiting for one or more people |
| Completing | Everyone has signed. The finished document is being made |
| Completed | The finished document is ready |
| Declined | Someone declined. Nobody else can sign it |
| Cancelled | You stopped it. Every link stopped working |
| Expired | The sign-by date passed before everyone signed |

A document cannot be cancelled once everyone has signed. A document that is out for signing
cannot be deleted; cancel it first.
